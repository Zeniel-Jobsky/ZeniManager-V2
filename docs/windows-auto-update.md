# Windows 앱 업데이트

기존 자동 업데이트 기능이 없는 앱은 최초 한 번 새 설치파일을 실행해야 합니다. 같은 appId와 설치 경로를 사용해 기존 앱을 갱신합니다. 이후부터는 앱 시작 15초 후 새 버전을 확인하며, 도움말 → 업데이트 확인에서도 확인할 수 있습니다.

사용자가 업데이트 받기를 선택하면 앱이 다운로드합니다. 저장 완료 · 재시작을 선택해야 앱을 종료하고 NSIS 설치프로그램을 실행합니다. 나중에를 선택하거나 일반 종료하는 경우 자동 설치하지 않습니다. 앱이 파일을 받는 과정은 여전히 필요하지만 사용자가 웹에서 설치파일을 따로 찾을 필요는 없습니다.

electron-updater 6.6.2를 사용합니다. Windows 설치판에만 활성화하며 개발 실행에서는 비활성화합니다. 공개 GitHub Releases를 사용하므로 앱에 GitHub 토큰을 포함하지 않습니다. 릴리스에는 ASCII 파일명 설치파일, blockmap, latest.yml을 함께 게시합니다. electron-builder는 --publish never로 빌드만 수행하고 Actions의 Release 단계에서 게시합니다.

검증: node --test electron/updates.test.cjs에서 다운로드/재시작 동의 분리, 나중에, 최신 버전, 네트워크 오류, 동시 요청 중복 방지를 확인합니다. 실제 Windows 설치판 간 업데이트는 Windows 기기에서 별도 확인해야 합니다.
